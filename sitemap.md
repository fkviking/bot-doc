- [https://fkviking.github.io/bot-doc/](https://fkviking.github.io/bot-doc/) — Документация в браузере
- [llms.txt](https://fkviking.github.io/bot-doc/llms.txt) — Краткая карта для агентов
- [llms-full.txt](https://fkviking.github.io/bot-doc/llms-full.txt) — Полный текст всех страниц подряд, в порядке разделов
- [sitemap.md](https://fkviking.github.io/bot-doc/sitemap.md) — Этот файл — полный указатель страниц
- [sitemap.xml](https://fkviking.github.io/bot-doc/sitemap.xml) — Карта сайта для поисковых роботов

## Адреса страниц

- HTML-страница: `https://fkviking.github.io/bot-doc/docs/<страница>.html`
